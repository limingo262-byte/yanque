# YanQue Admin 日志分析

用户要求查询或分析 yanque-admin 故障时使用本 Skill。

## 分析流程

1. 确认时间范围、业务关键词或 guid；没有准确条件时先使用较短时间范围。
2. 调用日志查询工具查找 ERROR 或业务关键词。
3. 发现 guid 后，用同一 guid 查询请求上下文。
4. 提取异常类型、错误信息和第一处 yanque-admin 业务堆栈。
5. 用 `run_repository_command` 先 rg 定位文件，再用 sed 或 nl 读取报错行附近代码。
6. 用日志事实和源码逻辑交叉验证后再下结论，不读取整个仓库。

## 判断标准

- 日志和源码相互印证：说明已确认原因。
- 只有部分线索：说明推测依据和待确认项。
- 证据不足：明确缺少的日志、上下文或源码版本，不编造原因。

## 输出格式

按照以下顺序输出：问题结论、影响范围、判断依据、处理建议、待确认信息。区分运营可以处理的事项和需要研发处理的事项。

## 安全限制

只分析 yanque-admin。源码工具只能执行只读命令，不得修改文件、执行 shell 拼接或读取密钥、Token、`.env`、私钥和证书。日志输出前脱敏用户手机号、Token 和其他敏感信息。
