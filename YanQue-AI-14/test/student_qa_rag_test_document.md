# 燕雀教育学生问答测试文档

本文档用于测试学生端 AI 问答的 RAG 召回、重排和回答效果。内容以培训班咨询场景为主，包含课程价格、课程安排、报名优惠、退费规则和学习服务。

## Java 培训班价格

燕雀教育 Java 就业班标准价格为 12800 元。

Java 就业班包含 Java 基础、面向对象编程、MySQL 数据库、Spring Boot、前后端分离项目、简历辅导和模拟面试。

如果学生咨询“Java 多少钱”“Java 培训班价格”“学 Java 要花多少钱”，可以回答：Java 就业班标准价格是 12800 元，具体优惠以报名时的活动为准。

## Java 课程周期

Java 就业班学习周期为 4 个月。

课程采用“基础语法 + 企业项目 + 面试冲刺”的学习路径。前 1 个月主要学习 Java 基础和 MySQL，中间 2 个月学习 Spring Boot、接口开发和项目实战，最后 1 个月进行综合项目、简历优化和面试训练。

## Python 人工智能班价格

Python 人工智能入门班标准价格为 9800 元。

课程内容包括 Python 基础、数据处理、FastAPI 接口开发、提示词工程、RAG 知识库问答、向量数据库和大模型 API 调用。

如果学生问“AI 课程多少钱”“Python AI 班价格”，可以回答：Python 人工智能入门班标准价格是 9800 元。

## 前端开发班价格

前端开发班标准价格为 8800 元。

课程内容包括 HTML、CSS、JavaScript、TypeScript、React、Vite、接口联调、后台管理系统开发和项目部署。

前端开发班适合希望从网页开发、管理后台、可视化页面入门的学生。

## 报名优惠

燕雀教育会不定期提供报名优惠。

常见优惠包括早鸟优惠、老学员推荐优惠、团报优惠和节假日活动优惠。优惠金额通常为 500 元到 2000 元不等，具体以报名当天招生老师确认的信息为准。

如果学生问“有没有优惠”“能不能便宜一点”，可以回答：可能有阶段性优惠，需要以报名当天活动为准。

## 分期付款

Java 就业班、Python 人工智能入门班和前端开发班都支持分期付款。

学生可以选择一次性付款，也可以申请分期。分期方案需要根据学生个人情况和当期合作平台规则确认。

如果学生问“可以分期吗”“能不能先交一部分”，可以回答：课程支持分期付款，具体分期方式需要联系招生老师确认。

## 退费规则

开课前 7 天内，学生如果因为个人原因无法参加学习，可以申请全额退费。

正式开课后，如果学生已经参加课程学习，退费金额会根据已学习课时、资料使用情况和服务消耗情况计算。

如果学生问“报名后能退吗”“学了一半不想学了怎么办”，可以回答：开课前通常可以申请退费，开课后需要按实际学习进度和服务情况计算退费金额。

## 上课方式

燕雀教育课程支持线上直播和线下面授两种方式。

线上直播适合外地学生或时间不固定的学生。线下面授适合希望现场学习、需要老师当面督促的学生。

所有直播课程都会提供回放，学生可以在课后复习。

## 学习服务

报名后，学生可以获得班主任督学、作业批改、阶段测评、项目辅导、简历指导和模拟面试服务。

如果学生学习中遇到代码报错，可以在学习群中提问，也可以预约老师答疑。

## 就业服务

Java 就业班提供就业辅导服务，包括简历优化、项目包装、面试题训练和模拟面试。

就业服务不等于保证就业。学校会帮助学生提升项目能力和面试能力，但最终就业结果和学生学习投入、基础水平、面试表现以及市场环境有关。

如果学生问“包就业吗”，可以回答：课程提供就业辅导，但不承诺百分百就业。

## 适合人群

Java 就业班适合零基础或基础较弱、希望系统学习后端开发的学生。

Python 人工智能入门班适合对 AI、大模型应用、RAG 知识库和 Python 接口开发感兴趣的学生。

前端开发班适合希望学习网页开发、React 项目和后台管理系统开发的学生。
